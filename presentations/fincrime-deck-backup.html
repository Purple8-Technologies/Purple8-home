Module 2 · Detection

Six crypto crime typologies
detected natively

Purple8 detects patterns that single-chain, cloud-based tools miss, including cross-chain layering and DeFi-based laundering.

01
Peeling Chains

Linear chains of 1-in-1-out wallets with no economic rationale. The graph detects long-hop paths with no branching, a classic obfuscation technique.

02
Mixing / Tumbling

CoinJoin many-to-many patterns. Timing correlation across inputs flags coordinated tumblers even when individual transactions look clean.

03
Cross-Chain Layering

CEX → DEX swap → bridge → new chain → CEX. Multi-hop traversal across Bitcoin, Ethereum, Solana, Tron, Polygon in a single graph query.

04
Both-Sides Betting

Same entity bets YES and NO on a market through different wallets, converting dirty crypto to "winnings". Common-input clustering catches it.

05
NFT Wash Trading

Community detection finds wallets buying and selling the same NFT to each other, identifying price inflation rings and mixer-disguised royalties.

06
Structuring

Sub-threshold transactions across multiple wallets. Temporal aggregation on SENT edges with amount + time windows catches coordinated splitting.

// Cross-chain layering — single query across all chains graph.traverse( start="ETH:0xA1b2...", edge_type="SENT|BRIDGED_VIA|SWAPPED|DEPOSITED_AT", depth=6, follow_chain_boundaries=True ) // → Traces: ETH_Wallet → Wormhole bridge → SOL_Wallet → Jupiter DEX → USDC → Binance withdrawal // → No existing tool follows this path across chains in a single query

Module 3 · The Unique Crime Vector

Prediction markets create a crime
no other tool can detect

Unlike stocks or crypto, the "event" being predicted can be influenced by the bettor. Connecting position, identity, corporate relationship, and outcome requires a graph that spans on-chain data, KYC documents, and real-world events simultaneously.

// Insider + event manipulation detection Person_A ─PLACED_BET(YES, $50K)─► Market:"CompanyX_Acquired" │ EMPLOYEE_OF / ADVISOR_TO │ CompanyX ─ANNOUNCED─► AcquisitionEvent // Bet entry → announcement: 31 hours // Person_A profit: $89K → flagged
// Both-sides laundering detection Wallet_A ─BET_YES($100K)─► Market_X Wallet_B ─BET_NO($95K)──► Market_X graph.communities(edge_type="SAME_ENTITY") // → Wallet_A and Wallet_B: same controller // → $5K fee paid = clean "winnings" narrative
