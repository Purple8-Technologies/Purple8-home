📁

05 / 09
Pillar 1 · Market Data

"What data did you use
and when did you pull it?" Always answerable.

The problem today

  • Market data enters a report as a paste. There is no record of where it came from or when it was pulled.
  • If a regulator asks which close price or earnings estimate was used, the analyst has to find the original file — if it still exists.
  • Different analysts may use different data snapshots for the same security with no way to detect the inconsistency.
  • The link between a data point and the recommendation it supports exists only in the analyst's head.

With Purple8

  • Data files dropped into a watched folder are ingested automatically — no analyst action required.
  • Every data point is stored with the exact date and time it was sourced. Historical snapshots are always retrievable.
  • Each figure cited in a recommendation is permanently linked to the source data that supported it — the connection is stored, not inferred.
  • A compliance query — "show me the data behind this recommendation" — is answered in seconds, not hours.

07 / 09
Pillars 4 & 5 · Publishing + Client Access

Approval triggers publication.
Clients find everything. Miss nothing.

Publishing

  • The moment a report is approved, it is distributed — email, client portal, Bloomberg, and any other channel — simultaneously. No manual step.
  • Every delivery is logged. You know who received what and when — not just who was on the distribution list.
  • Retraction is a single operation. It records the correction and preserves the full history of what was published and when.
  • If a delivery fails, it retries automatically. No duplicate sends.

Client Research Portal

  • Clients search by meaning, not keywords — a query about "European bank capital concerns" finds the relevant reports even if those exact words don't appear.
  • Related coverage, superseded ratings, and linked issuers surface automatically — not buried in separate searches.
  • Each client only sees the coverage they're entitled to — enforced at the search layer, not managed as a separate access list.
  • Clients are notified in real time when a report they follow is published — no polling, no email digests.
