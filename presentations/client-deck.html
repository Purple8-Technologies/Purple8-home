What Purple8 Is

Your complete AI backend.
One process. Zero external deps.

Purple8 is an embedded multi-model database purpose-built for AI applications. It runs in-process alongside your application — no separate server to manage, no network hops, no complex orchestration.

$ pip install purple8-hyper-graph

# That's it. You now have:
from purple8_graph import GraphEngine

g = GraphEngine()
# ↑ graph + vector + search + workflows
# + auth + encryption + MCP server
# all running in this one object
🗄️

Graph + Document Store

Store nodes, edges, and properties. Query with BFS, Dijkstra, PageRank, and community detection, all built in.

🔍

Vector + Full-Text Search

HNSW ANN vector search + full-text, hybrid-fused in a single query. Graph-guided for 80%+ segment skipping.

🤖

74 MCP Tools

Any MCP-compatible AI agent operates the entire backend through 74 native tools across 11 namespaces.

🔄

Journey Engine

Multi-stage workflows with SLA enforcement, human approval gates, and an immutable audit trail, all built in.

🔐

Security by Default

AES-256-GCM encryption at rest, 4-tier RBAC, multi-tenancy, and a SOC threat-detection vertical, all active from first instantiation.

📄

DocIntel Pipeline

70-format document intelligence: PDF, Word, IFC, BIM, images, code. Parse → extract → commit to graph in one call.
