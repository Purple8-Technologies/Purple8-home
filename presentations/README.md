# Purple8 Presentations

Two standalone HTML decks — no server required, no external dependencies. Open in any browser.

## Files

| File | Audience | Slides | Purpose |
|------|----------|--------|---------|
| `investor-deck.html` | Investors / VCs | 13 slides | Problem, tech differentiation, products, dog-fooding, market, business model, traction, ask ($3M seed) |
| `client-deck.html` | Potential customers | 11 slides | Pain points, what Purple8 replaces, how it works, Journey Engine, DocIntel, pricing, next steps |

## Usage

```bash
# Open directly in browser
open presentations/investor-deck.html
open presentations/client-deck.html
```

Or just double-click the `.html` file.

## Navigation

| Key | Action |
|-----|--------|
| `→` / `Space` | Next slide |
| `←` | Previous slide |
| `F` | Toggle fullscreen |
| `Home` | First slide |
| `End` | Last slide |

## Print to PDF

1. Open in Chrome or Edge
2. Press `Ctrl+P` / `Cmd+P`
3. Set destination to "Save as PDF"
4. Set layout to **Landscape**, margins **None**, scale **90%**
5. Enable "Background graphics"

## Notes

- `investor-deck.html` has a **Confidential & Proprietary** banner — remove the `.confidential` CSS rule if sharing publicly
- Both decks are fully self-contained — safe to email as a single file
- Designed for 1280×720 (16:9). Works on any screen size via CSS scaling.
